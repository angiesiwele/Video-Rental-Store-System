# Video-Rental-Store-System
This programme is designed to manage a video store’s rental system that will enable a the store to to keep record of all their customers as well as their videos and video hires. This system has a server and client side applications. The server application connects to a MySQL database called video_store.sql that store data on customers, videos and video hires and returns . The client side application allows the user to insert, update and request data from the MySQL video_store.sql database.
This Programme has four Functions:
1. Registering Customers
2. Registering Videos
3. Hiring Videos
4. Returning Videos
